Требуется реализовать графическую обёртку над SQL-базой данных (GUI интерфейс) на C++ с помощью FLTK
Программа должна реализовывать следующий функционал:
	1) Создание базы данных
	2) Выбор базы данных для просмотра
	3) Занесение новых полей в базу данных
	4) Просмотр полей базы данных
	5) Редактирование полей базы данных
Обязательно использовать в коде:
	1) Наследование (напр. наследование от классов FLTK)
	2) Написать свой родительский класс и от него наследоваться
	3) Реализовать перегрузку 3 операторов
	4) Продемонстрировать использование исключений
	5) Задействовать полиморфизм, использовать upcast и downcast
	6) Использовать только умные указатели (разрешается использование обычного указателя в отдельно взятом случае, если какая-то third-party функция принимает только обычные указатели)
Используемое программное обеспечение:
	1) SQLite для SQL
	2) FLTK для GUI
